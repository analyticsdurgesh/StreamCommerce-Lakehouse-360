# Interview Talking Points

- Start with the business problem: executives need trusted revenue, customer, inventory, and payment KPIs from messy operational events.
- Explain the source simulation: six services emit realistic imperfect events, which is closer to production than a static CSV-only project.
- Walk through each layer: Bronze for replay, Silver for trust, Gold for decisions.
- Emphasize quarantine: invalid data is isolated and explainable rather than silently deleted.
- Mention production extensions: Schema Registry, Structured Streaming checkpoints, Databricks workflows, IAM roles, monitoring, and cost controls.
